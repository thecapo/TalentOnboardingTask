# Talent Onboarding Task

MVP Studios Talent Onboarding Task! This exercise is designed to introduce to the technologies will be using as part of the project team. 
It is built using a simple admin application to manage a store's inventory and sales operations. This app will enable the handling of Create, Read, Update, and Delete (CRUD) operations for the following entities: Customer, Product, Sales, and Store.
